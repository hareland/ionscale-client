# ionscale-client

> NOTE TO HUMANS: This is 60-80% generated by AI, it is built from the ionscale protobuf definitions and the Connect
> protocol spec. If you find a bug or missing RPC, please open an issue or PR.
> I built this to use for myself, but it might save you some time if you want to build a TypeScript client for ionscale
> without having to deal with gRPC or protobufs.

A TypeScript client for [ionscale](https://github.com/jsiebens/ionscale) administration.
RPC API. It implements the [Connect RPC protocol](https://connectrpc.com/docs/protocol)
used by ionscale's `ionscale.v1.IonscaleService`, so it can talk to any ionscale
server without needing a gRPC runtime.

- Fully typed requests/responses, validated with [Zod v4](https://zod.dev)
- HTTP requests performed with [`ofetch`](https://github.com/unjs/ofetch)
- Zero dependency on protobuf/gRPC tooling — plain JSON over HTTP, as used by
  the Connect protocol
- Ships both ESM and CJS builds with bundled type declarations

## Installation

```bash
pnpm add ionscale-client
```

## Usage

```ts
import { IonscaleClient } from "ionscale-client";

const client = new IonscaleClient({
  baseUrl: "https://ionscale.example.com",
  token: process.env.IONSCALE_TOKEN,
});

const tailnets = await client.tailnets.list();
const tailnet = tailnets[0];
const machines = await client.machines.list({ tailnetId: tailnet!.id });

for (const machine of machines) {
  console.log(machine.name, machine.ipv4);
}
```

The `token` option also accepts a (possibly async) function, useful when the
credential needs to be refreshed or generated on demand:

```ts
const client = new IonscaleClient({
  baseUrl: "https://ionscale.example.com",
  token: async () => await getShortLivedToken(),
});
```

### Authenticating with the system admin key

If you're using
ionscale's [system admin key](https://jsiebens.github.io/ionscale/getting-started/#option-1-using-the-system-admin-key)
(e.g. the value configured via `IONSCALE_SYSTEM_ADMIN_KEY`), pass it as
`systemAdminKey` instead of `token`:

```ts
const client = new IonscaleClient({
  baseUrl: "https://ionscale.example.com",
  systemAdminKey: process.env.IONSCALE_SYSTEM_ADMIN_KEY,
});
```

The system admin key is not a bearer token itself — it's a private key that
must be used to sign a fresh, short-lived token for every request, the same
way the official `ionscale` CLI does. Passing it as `token` sends it verbatim
as a static `Authorization` header, which the server rejects with
`invalid token`.

### Error handling

RPC failures are surfaced as a `ConnectError`, exposing the Connect protocol
error `code` (e.g. `not_found`, `permission_denied`, `unauthenticated`), the
`message` returned by the server, and the original HTTP status:

```ts
import { ConnectError } from "ionscale-client";

try {
  await client.tailnets.get({ id: 999 });
} catch (error) {
  if (error instanceof ConnectError && error.code === "not_found") {
    console.log("tailnet does not exist");
  } else {
    throw error;
  }
}
```

### Streaming: interactive authentication

`Authenticate` is a server-streaming RPC used for interactive login flows. It
is exposed as an async generator:

```ts
for await (const message of client.auth.authenticate()) {
  if (message.authUrl) {
    console.log(`Visit ${message.authUrl} to authenticate`);
  }
  if (message.token) {
    console.log(`Received token: ${message.token}`);
  }
}
```

## Supported RPCs

All RPCs defined by `ionscale.v1.IonscaleService` are implemented as methods,
grouped into namespaced resource clients that mirror the shape of the API (e.g. `client.tailnets.list()`,
`client.machines.get(...)`). Methods that
would otherwise return a wrapper object whose only field is the requested
entity (e.g. `{ tailnet: ... }`) return that entity directly instead.

### Server info / auth

| Method                | Description                                                      |
|-----------------------|------------------------------------------------------------------|
| `getVersion()`        | Returns `{ version, revision }` of the ionscale server.          |
| `auth.authenticate()` | Async generator streaming `AuthenticateResponse` login messages. |

### Tailnets (`client.tailnets`)

| Method                                                                         | Returns                                 |
|--------------------------------------------------------------------------------|-----------------------------------------|
| `create(request)`                                                              | The created `Tailnet` (or `undefined`). |
| `update(request)`                                                              | The updated `Tailnet` (or `undefined`). |
| `get(request)`                                                                 | The `Tailnet` (or `undefined`).         |
| `list(request?)`                                                               | `Tailnet[]`                             |
| `delete(request)`                                                              | `DeleteTailnetResponse` (empty).        |
| `enableFileSharing(request)` / `disableFileSharing(request)`                   | Empty response.                         |
| `enableServiceCollection(request)` / `disableServiceCollection(request)`       | Empty response.                         |
| `enableSSH(request)` / `disableSSH(request)`                                   | Empty response.                         |
| `enableMachineAuthorization(request)` / `disableMachineAuthorization(request)` | Empty response.                         |

### DNS (`client.dns`) / IAM (`client.iam`) / ACL (`client.acl`)

| Method             | Returns                                         |
|--------------------|-------------------------------------------------|
| `dns.get(request)` | The `DnsConfig` (or `undefined`).               |
| `dns.set(request)` | `SetDnsConfigResponse` (`{ config, message }`). |
| `iam.get(request)` | The IAM policy, as a `string`.                  |
| `iam.set(request)` | Empty response.                                 |
| `acl.get(request)` | The ACL policy, as a `string`.                  |
| `acl.set(request)` | Empty response.                                 |

### Auth keys (`client.authKeys`)

| Method            | Returns                                                                                                                  |
|-------------------|--------------------------------------------------------------------------------------------------------------------------|
| `get(request)`    | The `AuthKey` (or `undefined`).                                                                                          |
| `create(request)` | `CreateAuthKeyResponse` (`{ authKey, value }`), since `value` carries the plaintext key alongside the created `authKey`. |
| `delete(request)` | Empty response.                                                                                                          |
| `list(request)`   | `AuthKey[]`                                                                                                              |

### Users (`client.users`)

| Method            | Returns         |
|-------------------|-----------------|
| `list(request)`   | `User[]`        |
| `delete(request)` | Empty response. |

### Machines (`client.machines`)

| Method                  | Returns                         |
|-------------------------|---------------------------------|
| `get(request)`          | The `Machine` (or `undefined`). |
| `list(request)`         | `Machine[]`                     |
| `setName(request)`      | Empty response.                 |
| `authorize(request)`    | Empty response.                 |
| `expire(request)`       | Empty response.                 |
| `delete(request)`       | Empty response.                 |
| `setKeyExpiry(request)` | Empty response.                 |

### DERP maps (`client.derp`)

| Method           | Returns                                          |
|------------------|--------------------------------------------------|
| `getDefault()`   | The default DERP map, base64-encoded `string`.   |
| `get(request)`   | The tailnet's DERP map, base64-encoded `string`. |
| `set(request)`   | The updated DERP map, base64-encoded `string`.   |
| `reset(request)` | Empty response.                                  |

### Subnet routes / exit nodes (`client.routes`)

| Method                     | Returns                                                   |
|----------------------------|-----------------------------------------------------------|
| `get(request)`             | `GetMachineRoutesResponse` (`{ machineId, routes }`).     |
| `enable(request)`          | `EnableMachineRoutesResponse` (`{ machineId, routes }`).  |
| `disable(request)`         | `DisableMachineRoutesResponse` (`{ machineId, routes }`). |
| `enableExitNode(request)`  | `EnableExitNodeResponse` (`{ machineId, routes }`).       |
| `disableExitNode(request)` | `DisableExitNodeResponse` (`{ machineId, routes }`).      |
